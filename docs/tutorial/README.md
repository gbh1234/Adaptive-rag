# 项目教学文档

本套文档是"基于 Adaptive-RAG 的电商客服系统"的教学材料。

全书按**技术主线**组织，共 **12 个部分**，并按"打基础 → 提质量 → 管上下文 → 做决策 → 控风险 → 拿证据与上生产"六个阶段循序渐进。评测独立成部分，但不前置，放在技术讲完之后作为验证环节。

---

## 阅读方式

每个部分一个文件夹，内含一份 `00-说明.md` 作为导读，以及若干篇正文。

读者可以按顺序通读，也可以按需跳读。每篇正文的结尾都有一句"指标回指"，指向第 11 部分"评测体系"中的对应指标。
