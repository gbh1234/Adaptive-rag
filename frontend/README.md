# Adaptive RAG Web 前端

基于 React、TypeScript 和 Vite 的聊天工作台。界面采用 ChatGPT 式布局，支持流式回答、来源引用、本地会话搜索与人工确认卡片。

流式接口只在答案完成校验后发送可展示的文本，不向用户展示模型生成的内部 JSON、检索策略或耗时信息。生成过程中页面显示等待状态。

## 本地运行

需要 Node.js 20.19+ 或 22.12+，以及 npm。

先在仓库根目录启动 8000 端口的 FastAPI，再开一个终端：

```bash
cd frontend
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173`。Vite 将 `/api` 代理到 `http://127.0.0.1:8000`，本地开发无需配置 CORS。

## 构建与检查

```bash
npm test
npm run build
```

构建结果在 `frontend/dist`。FastAPI 检测到该目录后会在 `/` 提供页面；Docker 镜像会在 Node 构建阶段自动生成并复制它。

## 数据与身份边界

- 浏览器以带版本号的 `localStorage` 保存会话列表和可见消息，最多保留 50 个会话，每个会话最多 100 条消息。后端目前没有历史列表接口；清除浏览器数据或换浏览器后，本地列表不会恢复。
- 后端返回的 `session_id` 会随会话保存，继续对话时复用。
- 待确认操作在服务端进程中保留 15 分钟；服务重启或请求落到另一进程时，需要重新发起该操作。
- `VITE_DEMO_USER_ID` 默认为 `u_demo`，仅用于本地演示。后端**尚不认证**请求中的 `user_id`。面向不可信用户部署前，必须由可信认证层在服务端绑定身份。
- `VITE_API_BASE` 可指向独立部署的 API；此时该 API 需要明确允许前端来源。
